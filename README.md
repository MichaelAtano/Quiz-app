# Premier League Quiz App

A browser-based multiple-choice quiz testing knowledge of Premier League football. Built as a personal project to practise JavaScript, DOM manipulation and interactive web development.

## Features

- 10 Premier League football questions
- Four answer options per question
- Visual feedback for correct and incorrect answers
- Score tracking
- Question counter showing progress
- Final score screen
- Restart functionality
- Prevents players from skipping questions without answering
- Responsive layout for smaller screens

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- GitHub Pages

## How to Run Locally

1. Clone or download this repository.
2. Open `index.html` in a web browser.

No installation or additional dependencies are required.

## What I Learned

- Selecting and updating HTML elements using the DOM
- Handling button clicks and user interactions
- Using conditional logic to check answers
- Tracking state, question progress and scores
- Testing interactive functionality and fixing bugs
